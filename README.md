# BrightNest Cleaning Co. — demo website

This is a fictional portfolio/demo website created to demonstrate a website service.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `brightnest-demo`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown there.

## Important before using for a real client
- Replace the fictional brand name, copy, contact details, service area, and images as appropriate.
- Obtain permission for all customer reviews and use only genuine reviews.
- Connect the enquiry form to a real backend/form provider. The current form is a front-end demonstration and does not send or store enquiries.
- Confirm image licenses and replace any images that are unsuitable for the client's use.
- Add the client's privacy policy and any required legal disclosures.
